# line-calc
El nombre significa lo que es: algo para calcular pero en una linea en la terminal, está hecha en ensamblador porque queria hacer algo en ensamblador nomás (significa nada más).

# INSTALACION 
Asegúrate de tener instalado `nasm` y `gcc` en tu sistema Linux.
Clona el repositorio
git clone [https://github.com/OdpeYT/line-calc.git](https://github.com/OdpeYT/line-calc.git)
cd line-calc

# USA
./line-calc 2 + 2
